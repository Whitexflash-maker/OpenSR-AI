# SuperScale — ফোনের জন্য গেম-ক্লাস আপস্কেলার

একটা সম্পূর্ণ, বিল্ড-রেডি Android অ্যাপ (Kotlin + OpenGL ES 3.0) যা **DLSS-এর মতো
কাজ** করে — কিন্তু ফোনে সত্যিই যা চলে সেই টেকনিক দিয়ে।

> **সত্যি কথা আগে:** আসল DLSS ফোনে চলে না। DLSS একটা নিউরাল নেটওয়ার্ক যা
> NVIDIA-র Tensor Core-এ চলে এবং গেম ইঞ্জিন থেকে motion vector/depth buffer
> চায়। তাই NVIDIA-র DLSS SDK মোবাইলের জন্য নেই — এবং কোনো থার্ড-পার্টি "DLSS
> অ্যাপ" বানায়নি।
>
> যা বানানো যায় — এবং এই অ্যাপটাই তা — হলো **EASU-ক্লাস spatial upscaling +
> RCAS contrast-adaptive sharpening** (FSR 1-এর পাইপলাইন), যা যেকোনো Adreno/Mali
> GPU-তে চলে। এটা DLSS-এর সমান না, কিন্তু বাইলিনিয়ারের চেয়ে স্পষ্টভাবে ভালো।

---

## যা কাজ করে

| ফিচার | বিস্তারিত |
|---|---|
| **লাইভ ডেমো** | প্রসিডিউরাল ৩ডি দৃশ্য কম রেজোলিউশনে রেন্ডার → রিয়েল-টাইমে আপস্কেল। FPS + ইন্টারনাল রেজোলিউশন লাইভ দেখা যায়। |
| **মোড টগল** | স্ক্রিনে ট্যাপ বা বাটনে **Bilinear ↔ Smart**। পার্থক্য সাথে সাথে চোখে পড়ে। |
| **রেন্ডার স্কেল** | ২৫% – ১০০% স্লাইডার। ৫০%-এ রেন্ডার করে ১০০% আউটপুট — এখানেই পারফরম্যান্স লাভ। |
| **শার্পনেস** | ০.০ – ১.০ RCAS স্ট্রেংথ, লাইভ। |
| **ছবি আপস্কেল** | গ্যালারি থেকে ছবি → ২x আপস্কেল → `Pictures/SuperScale`-এ PNG সেভ + প্রিভিউ। |

## পাইপলাইন

```
        ┌─────────────────┐
        │  Pass 1: RENDER │   দৃশ্য ৫০% রেজোলিউশনে রেন্ডার  (এখানেই লাভ)
        └────────┬────────┘
                 ▼
        ┌─────────────────┐
        │  Pass 2: UPSCALE│   ১৬-ট্যাপ Lanczos-2 + bilateral range weighting
        │                 │   (EASU-ক্লাস edge-directed reconstruction)
        └────────┬────────┘
                 ▼
        ┌─────────────────┐
        │  Pass 3: RCAS   │   Contrast Adaptive Sharpening, anti-ringing clamp
        └────────┬────────┘
                 ▼
              ডিসপ্লে
```

Pass 2 ও 3 মিলেই DLSS যা নিউরাল নেটওয়ার্ক দিয়ে করে তার হ্যান্ডক্রাফটেড
মোবাইল সমতুল্য।

## প্রমাণ (রেফারেন্স ইমপ্লিমেন্টেশন)

শেডারগুলোর হুবহু লজিক Python-এ পোর্ট করে ১৯২০×১০৮০ টেস্ট ফ্রেমে মাপা হয়েছে:

| | PSNR vs নেটিভ | Edge energy |
|---|---|---|
| বাইলিনিয়ার | 24.12 dB | 2.131 |
| Smart (Lanczos-16) | 24.37 dB | 2.574 |
| **Smart + RCAS** | **24.44 dB** | **2.704** |

Edge energy = কতটা ফাইন ডিটেইল টিকে আছে। বাইলিনিয়ারের ২.১৩ থেকে **২.৭০
(+২৭%)** — অর্থাৎ টেক্সট ও পাতলা লাইন স্পষ্টভাবে ধারালো থাকে।

## বিল্ড করবেন কীভাবে

**Android Studio (সবচেয়ে সহজ):**
1. Android Studio → *Open* → এই ফোল্ডারটা সিলেক্ট করুন
2. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন (wrapper নিজে তৈরি হবে)
3. ফোন কানেক্ট করে ▶ Run

**কমান্ড লাইন (Gradle ইনস্টল থাকলে):**
```bash
gradle wrapper          # একবার, gradle-wrapper.jar তৈরির জন্য
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

**শর্ত:** Android Studio Hedgehog+, JDK 17, ডিভাইসে OpenGL ES 3.0 (২০১৫-পরবর্তী
প্রায় সব ফোন)। `minSdk 24`।

## সীমাবদ্ধতা — যা এই অ্যাপ পারবে না

1. **অন্য অ্যাপের গেম আপস্কেল করা যাবে না।** Android স্যান্ডবক্সের কারণে একটা
   অ্যাপ অন্য অ্যাপের রেন্ডার আউটপুট পড়তে পারে না। এটা করতে **root + Vulkan
   layer hook (Magisk)** লাগে — ভঙ্গুর ও ঝুঁকিপূর্ণ।
2. **টেম্পোরাল আপস্কেল নেই** (SGSR2 / FSR2 / DLSS-এর মতো)। সেজন্য motion vector,
   depth buffer ও history buffer দরকার — যা গেম ইঞ্জিনের ভেতর থেকে আসে।
3. এই অ্যাপের নিজের রেন্ডার পাইপলাইনে () কাজ করে।
   নিজের Unity/UE গেমে বসাতে চাইলে Qualcomm-এর **SGSR** প্লাগইন ব্যবহার করুন,
   বা এই শেডারগুলো আপনার ইঞ্জিনের present স্টেজে বসান।

## পরবর্তী ধাপ (যদি আরও এগোতে চান)

- **নিজের গেমে ইন্টিগ্রেট** → Unity/UE-তে SGSR2 বা এই শেডার — সবচেয়ে ভালো ফল
- **PC গেম ফোনে** → Winlator / GameNative (এদের FSR সাপোর্ট বিল্ট-ইন)
- **Root থাকলে** → Vulkan layer দিয়ে present হুক
- **Adreno 850+** → Qualcomm Adreno Neural Fusion (NPU-তে AI আপস্কেল — DLSS-এর
  নিকটতম জিনিস যা ফোনে সত্যিই চলে)

## লাইসেন্স / অ্যাট্রিবিউশন

শেডারগুলো AMD FidelityFX FSR 1 (MIT) এবং Qualcomm SGSR (BSD-3) এর প্রকাশিত
অ্যালগরিদম থেকে অনুপ্রাণিত, কিন্তু স্বতন্ত্রভাবে লেখা। RCAS ধাপটি AMD-র
contrast-adaptive sharpening ফর্মুলেশন অনুসরণ করে। অ্যাপ কোড MIT।
